# RAWDATA

把本人有权处理的 TXT、Markdown、JSON、CSV、HTML、PDF 或 DOCX 文件放在这里，HARNESS 会在本地自动归档和处理。

Do not commit personal files to Git. This directory is ignored except for this README.

Place TXT, Markdown, JSON, CSV, HTML, PDF, or DOCX files that you are authorized to process here. HARNESS will archive and process them locally.
