# 开发路线图

## Phase 0：定义与治理（1—2 周）

交付：

- 冻结 L1 范围和术语表；
- 确定开源许可证与项目治理方式；
- 完成数据 Schema、威胁模型和同意模型；
- 准备一套完全虚构或已明确授权的演示人生数据；
- 写出 30—50 条 L1 基准测试题。

退出条件：任意一条数据都能回答“来自哪里、谁授权、模型做了什么、是否经本人确认”。

## Phase 1：可用的本地 MVP（4—6 周）

范围：

- 账户与本地身份库；
- Markdown、TXT、JSON、音频导入；
- 音频转写、证据定位、ThoughtCell 自动提取；
- 时间线、搜索和人工审核；
- 带引用的个人问答；
- 完整导出与删除。

退出条件：单个用户可导入至少 1,000 条记录，并在引用可追溯的前提下完成问答。

## Phase 2：Mindcopy 与 L1 评测（4—6 周）

范围：

- Mindcopy 生成、差异审查、签名和版本回滚；
- 风格、记忆、价值、决策和不确定性分项评测；
- 时间切片模式：以“某年时的我”回答；
- 支持者/反对者证据并列；
- 多模型对比和回归测试。

退出条件：每次模型或提示更新都能报告分项变化，而不是只展示主观演示效果。

## Phase 3：连接 dots 与个人 Agent（6—10 周）

范围：

- ThoughtCell 关系图谱与影响链审核；
- 创造力回溯、人生阶段总结和决策复盘；
- Todo 建议、写作协作等低风险 Agent；
- 每个工具单独授权、预览后执行、完整审计。

退出条件：系统能明确区分事实链、相关性链和因果假设，并允许用户纠正。

## Phase 4：生态与研究

候选方向：

- LifeContext DSL；
- 插件式数据连接器；
- 家庭与代际上下文；
- 可验证 Mindcopy 包格式与签名；
- MCP/A2A 接口；
- 经伦理审批的医疗或认知辅助研究。

链上身份、NFT 交易、死后自治代理和脑机接口不属于早期产品承诺，应作为独立研究与治理议题。

## 需要创始人尽快决定的事项

- 项目正式名称及中文名；
- 目标用户首先是个人创作者、普通个人，还是数字生命研究者；
- 默认只支持本地模型，还是允许用户自带云端 API；
- 代码许可证选择 Apache-2.0、MIT 或 AGPL-3.0；
- Mindcopy 文件规范是否与具体商业平台解耦；
- 哪些指标足以称为“L1 完成”，哪些只能称为体验指标。
